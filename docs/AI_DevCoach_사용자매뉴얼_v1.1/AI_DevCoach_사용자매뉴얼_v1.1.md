# AI DevCoach 사용자 매뉴얼 (v1.1)

> 버전: v1.1 (2026-11-19 업데이트)  

## 이용 안내

- 운영 주소: https://ai-dev-coach.vercel.app/
- 학습자 중심의 실행 테스트 화면을 기반으로 작성했습니다.
- 화면 버튼명·배치는 배포 버전에 따라 달라질 수 있습니다.
- AI 코칭 및 관리자 대시보드의 실제 캡처를 추가 반영했습니다. 관리자 하위 상세 화면은 미제공 상태입니다.

## 07. AI 학습 코칭

![AI 학습 코칭 실제 화면](images/ai_coaching_actual.png)

### 화면 목적
학습자가 AI에게 개발 및 학습 관련 질문을 입력하고, 답변과 참고 자료를 확인하는 화면입니다.

### 화면 구성
| 화면 요소 | 실제 화면에서 확인한 내용 |
|---|---|
| 상단 메뉴 | `대시보드`, `과제 관리`, `학습 통계`, `학습 코칭`, `AI 코치`, `GitHub 분석`, `수준 진단`, `진단 결과`, `로그아웃` |
| 제목 | `AI 학습 코치` |
| 대화 영역 | 사용자 질문과 AI 답변이 구분되어 표시 |
| 참고 자료 | AI 답변 아래 문서 제목과 `source_id` 형식의 출처 표시 |
| 메시지 입력 | `메시지` 입력 상자 |
| 전송 | `보내기` 버튼 |
| 저장 안내 | 완료된 질문과 답변이 계정별로 저장되며 재로그인 시 불러온다는 안내 |

### 이용 절차
1. 로그인 후 상단의 **AI 코치** 메뉴를 선택합니다.
2. 하단 **메시지** 입력란에 학습 질문을 작성합니다. 예: `RAG에서 출처를 표시해야 하는 이유를 알려줘`.
3. **보내기**를 클릭합니다.
4. AI 답변을 읽고, 표시되는 경우 **참고 자료** 및 출처 식별자를 확인합니다.
5. 다른 질문을 이어서 입력하여 학습을 계속합니다.
6. 이전 대화가 필요한 경우 재로그인 후 AI 코치 화면에서 대화가 표시되는지 확인합니다.

**화면 확인 사항:** 첨부된 실제 화면에는 파이썬의 AI 활용 이유를 묻는 질문과 AI 답변, 참고 자료 두 건이 표시됩니다. 대화 저장 안내는 확인되지만, 모든 계정에서 재로그인 복원까지 실제 테스트되었는지는 별도 검증이 필요합니다.

**주의:** AI 답변과 참고 자료는 학습 보조 정보입니다. 코드 실행 결과와 사실관계는 별도로 검증하세요.

## 08. 관리자 대시보드

![관리자 대시보드 실제 화면](images/admin_dashboard_actual.png)

### 화면 목적
등록 학습자의 학습계획 및 과제 수행 현황을 검색·조회하고, 선택한 학습자의 상세 상태를 살펴보는 관리자 화면입니다.

### 화면 구성
| 화면 요소 | 실제 화면에서 확인한 내용 |
|---|---|
| 상단 이동 | `학습자 화면`, `로그아웃` |
| 요약 지표 | `등록 사용자`, `진행 중인 계획`, `전체 완료율`, `보류 과제` |
| 사용자 검색 | `이메일, 이름 또는 학습 목표` 입력창과 `검색` 버튼 |
| 새로고침 | 검색 버튼 옆 새로고침 아이콘 |
| 사용자 목록 | 사용자별 이름, 이메일, 진도율, 완료 과제 수 |
| 사용자 상세 | 학습 목표, 과제 완료, 학습시간, 보류 과제 |
| 과제 현황 | `개인별 과제 수행 현황`, 주차별 과제 상태 |
| 계획 초안 | 사용자 상세 상단의 `계획 초안` 버튼 |

### 이용 절차
1. 관리자 권한으로 로그인한 후 **관리자 대시보드**를 엽니다.
2. 상단 지표를 통해 전체 등록 인원, 진행 중인 계획, 완료율 및 보류 과제를 확인합니다.
3. 특정 학습자를 찾으려면 **사용자 검색**에 이름·이메일·학습 목표 중 하나를 입력하고 **검색**을 누릅니다.
4. 왼쪽 사용자 목록에서 대상 학습자를 선택합니다.
5. 오른쪽 **사용자 상세**에서 학습 목표, 과제 완료 비율, 학습시간 및 보류 과제 수를 확인합니다.
6. 아래 **개인별 과제 수행 현황**에서 주차별 과제와 제출 상태를 확인합니다.
7. 필요한 경우 **계획 초안** 버튼을 선택합니다. 단, 버튼을 누른 뒤 나타나는 화면과 처리 절차는 제공된 캡처만으로 확인되지 않았습니다.
8. 학습자 화면으로 이동할 때는 상단 **학습자 화면**을 이용합니다.
