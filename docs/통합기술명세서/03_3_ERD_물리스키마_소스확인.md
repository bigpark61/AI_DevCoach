## 1. 검증 상태 및 증빙 등급

| 등급 | 의미 | 이번 문서의 근거 |
|---|---|---|
| **P-UI** | Neon production 콘솔 스크린샷에서 직접 관찰 | 프로젝트/브랜치/DB/스키마, 테이블 표시, 대화기록 표시 컬럼 |
| **S-CODE** | 이전 v2.0 기술설계서에 기재된 소스 정적 대조 결과 | 개발 SQLite DDL, API/함수 매핑, Agent 기록 저장 |
| **HYP** | 코드 기반 예상 또는 논리적 관계로 운영 PostgreSQL에서는 아직 미확정 | PK·FK, 데이터형, 인덱스, 기본값, nullable, 실제 관계 강제 여부 |
| **P-DB 미완료** | 시스템 카탈로그 조회 기반 확정 검사 | `information_schema`, `pg_catalog`, `alembic_version` 실제 값 미취득 |

> **중요:** Neon 앱은 연결되었으나 이번 세션에서 연결 도구가 `list_projects`/`search` 호출에 `Tool not found`, `get_database_tables`에 유효하지 않은 `project_id` 오류를 반환했습니다. 그러므로 DB 시스템 카탈로그를 직접 쿼리했다거나 운영 PK/FK를 확정했다고 주장할 수 없습니다. 운영 데이터에 변경은 수행하지 않았습니다.

## 2. 운영 콘솔에서 직접 관찰한 사실 (P-UI)

- 운영 프로젝트 `AI_DevCoach`, 브랜치 `production`, DB `neondb`, 스키마 `public`.
- 왼쪽 Tables 목록에서 다음 13개 테이블명이 식별됨: `alembic_version`, `assessments`, `github_analysis_runs`, `learning_activity_logs`, `learning_time_logs`, `password_reset_tokens`, `plan_revision_requests`, `plans`, `profiles`, `sessions`, `task_progress`, `task_submissions`, `users`.
- 우측 선택 테이블은 이름이 완전히 보이지 않으나 컬럼 `id bigint(bigserial 표시)`, `user_id text`, `role text`, `content text`가 식별되고 `user`/`assistant` 역할의 **4개 행**이 표시됨. v2 코드의 `agent_chat_messages`와 구조가 부합하나 **선택 테이블명은 스크린샷에서 직접 확정 불가**.
- `alembic_version` **테이블의 존재**는 확인되지만 실제 revision 값, migration 적용 완료 여부는 미확정.
- 목록이 스크롤 중이므로 이 화면만으로 전체 테이블 개수를 13개라고 단정하지 않음.

## 4. ERD — 코드 기반 논리 관계도 (운영 FK 미확정)

아래 연결선은 **개발용 SQLite 코드에 기반한 논리 관계**입니다. Neon PostgreSQL에서 실제 외래키 제약조건이 설정됐음을 뜻하지 않습니다. PK 표기도 개발 코드에 기반한 추정이며 `pg_constraint` 검증이 선행되어야 합니다.

## 5. 운영 DB로부터 확정해야 하는 항목

1. `public`의 전체 BASE TABLE/VIEW 목록과 개수
2. 테이블별 실제 컬럼, PostgreSQL 자료형, nullable, 기본값/identity
3. PK, UNIQUE, FK 및 CASCADE 정책, 복합키·참조 인덱스
4. `alembic_version.version_num` 실제 값과 리포지토리 migrations head 비교
5. 애플리케이션의 ORM/SQL 접근 방식과 운영 DB의 nullable/데이터형 정합성
6. `agent_chat_messages` 실재 여부 및 `id/user_id/role/content/sources_json/created_at` 열 대조

위 확인을 위한 **조회 전용 SQL**은 [05_Neon_운영스키마_검증SQL.md](03_5_Neon_운영스키마_검증SQL.md)에 있습니다. 실제 운영 스키마를 확보한 뒤에만 제목의 '운영 물리 ERD 확정'을 사용해야 합니다.
