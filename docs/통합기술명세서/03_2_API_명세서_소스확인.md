# AI DevCoach 실제 소스 기반 API 명세서 — v3.0 Neon production 근거 추가

- 기준: v2.0에서 정리한 공개 `main` 브랜치 `backend/main.py` 소스 정적 대조
- **주의:** Neon Console 화면은 데이터 테이블 존재의 근거이며, 특정 API 경로의 운영 성공이나 반환 스키마를 증명하지 않습니다. 실제 운영 API 호출 및 DB 처리 결과는 미검증.
- 인증: `devcoach_session` HttpOnly Cookie, 별도 표기가 없으면 로그인 필요
- 데이터: JSON; Pydantic 검증 오류 일반적으로 HTTP 422
- **확인 범위:** 아래는 실제 데코레이터를 확인한 경로. 누락된 세부 라우트는 `http://127.0.0.1:8000/openapi.json`을 통해 자동 추출·대조 필요

## 주요 입력 스키마 (코드 확인)

- `SignupInput`: `email`, `password`(8~128자), `terms_agreed`, `privacy_agreed`
- `ProfileInput`: `nickname`, `learning_goal`, `self_assessed_level`(`beginner|novice|intermediate`), `interest_skills`, `weekly_hours`(2~40), `duration_weeks`(4/8/12), `github_username`, `learning_notes`
- `AnswerInput`: `question_id`, `answer`(최대 5000자)
- `PlanGenerateInput`: `goal`, `duration_weeks`, `weekly_hours`, `difficulty`(`foundation|balanced|challenge`), `learning_style`(`project|examples|self_paced`), `focus_skills`, `additional_requirements`
- `TaskProgressInput`: `status`(`todo|in_progress|completed|blocked`), `learning_start_date`, `learning_notes`, `difficulty_notes`, `learner_memo`
- `TaskSubmissionInput`: `github_url`(선택), `explanation`(선택), 둘 중 하나 필수
- `GitHubAnalysisInput`: `repo_url`(https://github.com/owner/repo), `branch`(선택), `task_criteria`(선택)
- `AgentChatInput`: `message`(1~2000자), `history`(최대 8개, 사용자/assistant 역할); 서버는 DB의 최근 대화도 조회

## 예시 요청

```http
POST /api/github/analyses
Content-Type: application/json
Cookie: devcoach_session=<session>

{"repo_url":"https://github.com/bigpark61/AI_DevCoach","branch":"main","task_criteria":"README와 코드 품질 검토"}
```

```http
POST /api/agent/chat
Content-Type: application/json
Cookie: devcoach_session=<session>

{"message":"내 학습 진도를 알려줘","history":[]}
```

## 오류 및 제한

- 401: 미인증; 403: 관리자 권한 없음/공개 저장소 접근 거부; 404: 소유 리소스 또는 GitHub 리소스 없음; 409: 상태 충돌; 422: 입력 검증; 429: GitHub rate limit; 502: 외부 AI/GitHub 실패; 503: AI 제공자 설정 없음.
- GitHub 분석은 공개 저장소만 지원하고 브랜치 기준 commit SHA를 저장합니다.
- 운영 서비스 API의 실측 응답시간·성공률은 본 문서에서 측정하지 않았습니다.

## OpenAPI 자동 추출 (최종 제출 직전)

```powershell
python -m uvicorn backend.main:app --reload
# 브라우저에서 http://127.0.0.1:8000/docs 또는 /openapi.json
```

실행한 애플리케이션의 OpenAPI가 최종 API 목록의 우선 기준입니다. `backend/main.py`의 현재 실제 데코레이터와 자동 생성 명세를 비교하세요.
