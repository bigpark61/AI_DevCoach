# AI DevCoach 사용자 등록 및 프로필 등록 화면 설계서

화면설계서 v1.0 | 대상 기능: FR-01 사용자 등록 및 프로필 관리 | 개발 우선순위: 필수(MVP)

## 1. 설계 개요

목적: AI DevCoach 사용자가 계정을 생성하고 자신의 학습 목표, 개발 경험, 관심 기술 및 학습 가능 시간을 등록하여 AI 수준 진단과 맞춤형 학습계획 생성에 활용하도록 합니다.

사용자 등록과 학습 프로필 등록은 별도 단계로 구분합니다. 계정 생성에 필요한 정보는 최소화하고, 학습 관련 정보는 이후 수정할 수 있도록 설계합니다.

## 3. UI-03 학습 프로필 등록 화면

프로필은 AI 수준 진단의 초기 조건과 학습계획 수립에 활용합니다. 단, 사용자가 선택한 현재 수준은 자기평가 값이며, 실제 수준은 후속 진단 결과로 별도 산정합니다.

아래는 개발 화면에 적용할 수 있는 인터랙티브 시안입니다.

|`profile_completed`|BOOLEAN|Y|true|

### 3.2 프로필 검증 규칙

- 닉네임은 공백만으로 등록할 수 없으며 길이 제한을 적용합니다.
    
- 학습 목표와 현재 경험 수준은 반드시 선택합니다.
    
- 주당 학습 가능 시간은 2~40시간 범위로 제한합니다.
    
- 학습 기간은 MVP에서 4·8·12주 중 선택합니다.
    
- GitHub 사용자명은 선택 사항이며, 입력 시 허용 형식을 검증합니다.
    
- 사용자의 추가 메모는 화면 표시 시 HTML을 이스케이프 처리합니다.
    
- 프로필 수정 시 기존 진단 결과와 학습계획을 자동 삭제하지 않습니다.
    

## 4. UI-02 로그인 및 UI-04 프로필 수정

로그인 화면은 이메일, 비밀번호, 로그인 버튼, 비밀번호 재설정 링크, 회원가입 이동 링크로 구성합니다. 인증 실패 시 이메일 존재 여부를 노출하지 않는 일반화된 오류 메시지를 사용합니다.

프로필 수정 화면은 등록 화면과 동일한 입력 컴포넌트를 재사용합니다. 저장 시 변경된 항목만 갱신하고, 학습 목표나 주당 학습시간이 변경되면 다음 안내를 제공합니다.

> 학습 프로필이 변경되었습니다. 새로운 조건에 맞춰 학습계획을 다시 생성하시겠습니까?

재계획은 사용자가 승인한 경우에만 실행합니다.

## 6. Backend API 설계

|Method|API|요청·응답|
|---|---|---|
|POST|`/api/auth/signup`|이메일·비밀번호·동의 정보 → 가입 접수|
|POST|`/api/auth/login`|인증 정보 → 세션 또는 토큰|
|POST|`/api/auth/logout`|인증 세션 종료|
|GET|`/api/users/me`|사용자 기본정보 조회|
|POST|`/api/profiles`|최초 학습 프로필 등록|
|GET|`/api/profiles/me`|본인 학습 프로필 조회|
|PATCH|`/api/profiles/me`|본인 프로필 수정|

프로필 등록 요청 JSON 예시:

```
{
  "nickname": "DevLearner",
  "learning_goal": "AI Agent 웹서비스 개발",
  "self_assessed_level": "beginner",
  "interest_skills": ["Python", "FastAPI", "Git/GitHub"],
  "weekly_hours": 8,
  "duration_weeks": 4,
  "github_username": "devlearner",
  "learning_notes": "주말에 집중 학습"
}
```

인증 사용자 식별자는 요청 본문에서 신뢰하지 않고 서버의 인증 세션으로 확인합니다.

## 8. 개발 산출물과 구현 순서

이 화면 설계를 개발에 적용할 때는 다음 순서가 적합합니다.

1. DB 테이블 생성: 사용자 인증 테이블, 학습 프로필 테이블, 동의 이력 테이블
    
2. 인증 API 개발: 가입, 로그인, 이메일 인증, 비밀번호 재설정
    
3. 프로필 API 개발: 등록, 조회, 수정 및 입력 검증
    
4. Frontend 구현: 회원가입, 로그인, 프로필 등록·수정
    
5. 연계 개발: 프로필 저장 후 AI 수준 진단 화면 이동
    
6. 테스트: 입력 검증, 인증, 권한 및 저장·조회 확인
    

핵심 설계 원칙: 회원가입 정보는 최소화하고, 학습 프로필은 개인화 AI 서비스에 필요한 정보 중심으로 구성합니다. 특히 `self_assessed_level`과 이후 AI 수준 진단에서 계산되는 `assessment_level`을 구분하여 저장하는 것이 중요합니다.

이렇게 설계하면 FR-01을 완료한 뒤 FR-02 수준 진단, FR-03 학습계획 생성 기능을 별도 재설계 없이 연결할 수 있습니다.
