# 사용자 피드백

## 피드백 목적

비전공자와 처음 학습을 시작하는 사용자가 AI DevCoach를 이용하면서 느낀
불편 사항과 개선 의견을 정리한다. 각 의견에는 사용자가 직접 평가한
5점 만점 점수를 함께 기록했다.

## 주요 피드백

### 1. 문제의 길이와 기본 개념 설명 부족

- **평점:** 3.0/5
- 문제가 전반적으로 너무 길게 느껴졌다.
- 비전공자나 해당 주제를 처음 접하는 사용자를 위한 기본 개념 설명이
  부족해 문제를 따라가며 테스트하기 어려웠다.
- 이미 해당 내용을 알고 있는 사람을 대상으로 체크업하도록 설계된 것처럼
  느껴졌다는 의견이 있었다.

**개선 제안**

- 문제를 짧고 명확한 단위로 나눈다.
- 문제를 풀기 전에 핵심 개념과 용어를 간단히 설명한다.
- 초급·중급·고급 난이도를 구분하고, 초급 사용자가 단계적으로 학습할 수
  있도록 구성한다.

### 2. 관심 분야와 관계없는 문제 및 AI 대화 내용

- **평점:** 4.0/5
- 사용자가 선택한 관심 분야 외의 문제도 출제되는 점이 궁금하다는
  의견이 있었다.
- AI와 대화할 때도 관심 분야와 직접적인 관련이 없는 질문이나 답변이
  포함되는 경우가 있어, 이것이 의도된 동작인지 확인이 필요하다는
  의견이 있었다.

**확인 및 개선 제안**

- 관심 분야 외의 문제를 출제하는 이유와 범위를 사용자에게 안내한다.
- 관심 분야와 직접 관련된 문제를 우선 제공한다.
- 관련 없는 문제를 포함할 때에는 연관성을 설명하거나 사용자가 선택할 수
  있도록 한다.

### 3. 로그인·회원가입 흐름과 초기 선택값

- **평점:** 4.5/5
- 로그인 영역을 선택하면 바로 계정 만들기 화면으로 이동할 것으로
  예상했으나, 기대한 흐름대로 동작하지 않았다.
- 관심 기술을 선택하기 전에 파이썬 분야가 미리 선택되어 있는 이유가
  궁금하다는 의견이 있었다.
- 처음 공부하려는 사용자에게는 수준이 너무 높게 느껴졌다.
- 중소기업 대표가 제품을 홍보하는 것처럼 느껴지는 표현이 있어, 학습
  서비스보다는 광고처럼 보일 수 있다는 의견이 있었다.

**개선 제안**

- 로그인과 회원가입 버튼의 이동 경로와 동작을 명확히 한다.
- 관심 기술의 초기 선택값을 비워 두거나, 기본값이 선택된 이유를 안내한다.
- 처음 방문한 사용자를 위해 쉬운 난이도와 기초 학습 경로를 제공한다.
- 홍보성 문구를 줄이고 학습 목적과 사용자의 이점을 중심으로 안내한다.

### 4. 이용 시간 부담

- **평점:** 4.0/5
- 한 사용자는 서비스 이용에 시간이 너무 많이 걸린다는 점만 주요
  의견으로 남겼다.

**개선 제안**

- 전체 진단에 예상 소요 시간을 표시한다.
- 진단을 여러 단계로 나누고 중간 저장 및 이어하기를 제공한다.
- 빠르게 결과를 확인할 수 있는 간단 진단 모드를 제공한다.

### 5. 학습하지 않은 내용까지 포함되는 총점

- **평점:** 4.0/5
- 아직 학습하지 않은 내용까지 총점에 포함되는 점이 아쉽다는 의견이
  있었다.
- 학습 단계별 필터링 기능이 있으면 좋겠다는 제안이 있었다.

**개선 제안**

- 사용자가 학습한 범위와 아직 학습하지 않은 범위를 구분한다.
- 총점을 학습 완료 영역, 현재 학습 영역, 미학습 영역으로 나누어
  표시한다.
- 초급·중급·고급 또는 학습 단원별 필터를 제공한다.
- 미학습 영역은 평가 점수에 바로 반영하기보다 사전 진단 또는 추천
  영역으로 별도 표시한다.

## 종합 의견

사용자들은 서비스의 기본 방향과 개인화된 학습 지원에는 긍정적인 평가를
보였지만, 처음 접하는 비전공자가 이용하기에는 문제의 길이와 난이도,
기본 개념 설명, 진단 소요 시간에 대한 부담이 있었다. 또한 관심 분야와
평가 범위의 연결 관계가 명확하지 않고, 로그인·회원가입 및 초기 선택값의
동작이 사용자 기대와 다를 수 있었다.

우선적으로는 다음 개선이 필요하다.

1. 비전공자용 기초 설명과 단계별 난이도 제공
2. 문제 수와 진단 소요 시간 축소 또는 간단 진단 모드 제공
3. 관심 분야와 문제·AI 대화의 연관성 강화
4. 로그인·회원가입 및 관심 기술 선택 흐름 개선
5. 학습한 범위와 미학습 범위를 구분하는 점수 및 필터링 제공
