# RAG 학습자료

## 검색 증강 생성 흐름
RAG는 질문과 관련된 자료를 먼저 검색한 다음, 검색 결과를 문맥으로 넣어 언어 모델이 답변하게 합니다. 최소 흐름은 자료 수집, 작은 단위로 나누기, 검색, 근거가 포함된 생성, 출처 표시입니다.

검색 점수가 낮거나 근거가 없으면 답을 추측하지 말고 자료가 부족하다고 알려야 합니다. 답변의 핵심 주장에는 검색 결과의 출처 식별자를 연결하고, 사용자가 원문을 확인할 수 있게 합니다.

## 자료 품질과 검색 평가
자료에는 신뢰할 수 있는 출처, 제목, 갱신 시점을 기록합니다. 제목과 문맥이 끊기지 않도록 문서 구조를 따라 나누고, 지나치게 짧거나 중복된 조각은 피합니다.

검색 평가는 예상 질문과 정답 자료를 가진 작은 테스트셋으로 시작합니다. 상위 검색 결과에 정답 자료가 들어오는지, 출처가 답변을 뒷받침하는지, 자료가 없을 때 답변이 보류되는지를 함께 확인합니다. 임베딩을 도입하면 같은 모델과 차원을 문서와 질문에 사용해야 합니다.
