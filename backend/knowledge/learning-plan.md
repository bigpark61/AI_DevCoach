# 개인 학습계획 운영

## 과제와 학습 기록
학습계획은 목표, 주차, 과제, 완료 기준과 결과물로 구성합니다. 과제의 시작 전, 진행 중, 완료, 보류 상태는 학습자가 기록한 값으로 구분하고 완료 여부를 추정하지 않습니다.

학습시간, 제출물, 완료 상태는 각각 별개의 증거입니다. 완료율은 완료 상태가 확인된 과제만 계산하고, 실제 학습시간은 기록된 시간 로그의 합으로 계산합니다.

## 개인화된 다음 행동
다음 행동을 추천할 때는 현재 사용자의 승인된 계획, 과제 상태, 학습시간을 근거로 삼습니다. 보류 과제가 있으면 막힌 이유와 필요한 도움을 먼저 확인하고, 진행 중인 과제가 있으면 완료 기준과 남은 작업을 안내합니다.

새 계획이나 일정 변경은 기존 계획을 즉시 덮어쓰지 않습니다. 목표와 학습 가능 시간이 달라진 이유를 받고 수정안을 제안한 뒤 사용자가 승인하도록 합니다.
