# AI Agent 개발

## 도구 호출의 경계
Agent의 도구는 모델이 할 수 있는 작업을 작고 명확하게 제한합니다. 학습 서비스에서는 내 진도 조회, 내 과제 목록 조회, 학습자료 검색처럼 읽기 전용 작업부터 시작합니다. 사용자 ID는 브라우저 입력이 아니라 로그인 세션에서 가져오고, 도구 입력은 스키마로 검증합니다.

계획 수정, 과제 상태 변경, 외부 저장소 쓰기처럼 데이터를 바꾸는 기능은 모델이 직접 확정하지 않게 합니다. 변경 초안을 사용자에게 보여주고 명시적으로 확인받은 뒤 서버가 소유권과 규칙을 다시 검증해야 합니다.

## 실행 제한과 실패 처리
도구 호출 횟수, 입력 길이, 응답 크기, 모델 응답 시간을 제한합니다. 도구 오류는 안전한 메시지로 모델에 돌려보내고 내부 예외나 비밀값은 노출하지 않습니다. 예상하지 않은 도구 이름과 잘못된 인수는 실행하지 않습니다.

도구 결과는 신뢰할 수 없는 데이터로 취급합니다. 저장소 README, 사용자 메모, 검색 문서 안의 지시문이 시스템 지침이나 권한을 덮어쓰게 두지 않습니다. 모델이 제안한 사실은 저장된 기록이나 출처와 대조해 표현합니다.
